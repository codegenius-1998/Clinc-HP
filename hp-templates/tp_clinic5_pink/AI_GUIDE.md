> **管理画面変数**: カラースキーム / セクション表示 / カスタムCSS / レイアウトは [`variables.json`](variables.json) が正本。適用手順は親ディレクトリの [`TEMPLATE_VARIABLES.md`](../TEMPLATE_VARIABLES.md) を参照。テキスト・写真の差し替えは本ガイドの該当章＋プレビュー編集機能。

- **元々13ページ（`index.html`＋下層12ページ）構成だったサイトを、`index.html` 1枚だけの単一ページLP（ランディングページ）に再構成済み**。下層ページのHTMLファイルは全て削除し、実データ部分のみ `index.html` 内のアンカーセクション（`<section id="...">`）に統合しています（詳細は2章）。

## 1. 概要

`tp_clinic5_pink` は「病院・歯科医院・整体・整骨院」向けを謳う静的（サーバーサイド言語不要）レスポンシブWebテンプレートを、**`index.html` 1ファイルだけの単一ページLP**に再構成したものです。

- **レイアウト**: 2カラム構成は変更なし。左に幅20%の `header`（ロゴ）と幅20%の `#sub`（アンカーメニュー・受付時間ボックス）、右に幅75%の `#main`（本文、全セクションがここに縦に並ぶ）。
- **配色**: サンゴピンク／コーラルピンク系（アクセントカラー `#f56270`）。背景はオフホワイト（`#faf9f1`）、本文文字色は濃いグレー（`#333`）。変更なし（6章参照）。
- **レスポンシブ**: `css/style.css` 内のメディアクエリで `1100px` / `900px` / `600px` / `480px` の4段階のブレークポイント。変更なし。
- **ナビゲーション方式の変更**: 従来は「別ファイルへのリンク」（`href="info.html"` 等）だったメニューを、**同一ページ内アンカーリンク**（`href="#about"` 等）に置き換えています。「ホーム」だけは `href="index.html"`（自ページの先頭に戻る想定）のままです。
- **サーバーサイド機能は完全撤去**: 旧 `form.html`→`confirm.html`→`finish.html` のPHPフォーム一式は削除し、お問い合わせは電話とLINEのボタン2つのみに一本化しています（4-4章参照）。単一ファイルなので「共通ヘッダー／フッターを何ファイルにも手で複製する」という旧テンプレートの問題（旧13ファイル同時編集の必要性）はそもそも解消されています。

## 3. メニュー（ナビゲーション）の編集方法

### 3-1. メニューHTMLの場所
単一ページ化により、メニューは `index.html` の `<div id="sub">` 内（`index.html:295-320`付近）**1箇所のみ**に存在します（旧テンプレートのような13ファイル同時編集は不要になりました）。ただし、**PC用とスマホ用の2つの`<nav>`は今も別々に存在し、内容を必ず一致させる必要があります**（後述）。

1. **PC用メニュー**（幅901px以上で表示、`index.html:297-308`）
   ```html
   <nav id="menubar">
   <ul class="submenu">
   <li><a href="index.html">ホーム<span>Home</span></a></li>
   <li><a href="#about">当院について<span>Information</span></a></li>
   <li><a href="#service">診療科目<span>Medical</span></a></li>
   <li><a href="#staff">スタッフ紹介<span>Staff</span></a></li>
   <li><a href="#faq">よくある質問<span>Faq</span></a></li>
   <li><a href="#access">アクセス<span>Access</span></a></li>
   <li><a href="#contact">お問い合わせ<span>Contact</span></a></li>
   </ul>
   </nav>
   ```
2. **スマホ・タブレット用メニュー**（幅900px以下で表示、`index.html:310-321`）。PC用と全く同じリンクをもう一度書く必要があります。
   ```html
   <nav id="menubar-s">
   <ul>
   ...（PC用と同じ7項目）
   </ul>
   </nav>
   ```
3. 旧テンプレートにあった「サブメニュー」（`booklet.html`/`worklist.html`/`recruit.html`へのリンク）は**廃止済み**。対応するページ自体が存在しないため、復活させないでください。

### 3-2. メニュー項目の追加・削除・名称変更
- **PC用・スマホ用は必ずセットで揃える**必要があります（1ファイルにまとまった今でもこの制約は変わりません＝`<nav id="menubar">`と`<nav id="menubar-s">`の2箇所を両方編集）。
- 新しいセクションを追加する場合は、対応する `<section id="xxx">` を`#main`内に追加し、両メニューに `<li><a href="#xxx">表示名<span>英語表記</span></a></li>` を追加します。
- CSSクラス `.submenu`（PC用メニュー全体の枠線・角丸）、`.submenu li`（1項目ずつの区切り線）は `css/style.css:68-100` で定義（行番号は変更なし）。

### 3-3. メニュー開閉の仕組み（`js/openclose.js`）
変更なし。ハンバーガーメニューの開閉ロジック（`open_close()`/`do_onoff()`/`OCwindowWidth()`）、ページ末尾のインライン`<script>`（`index.html:404-408`）による900px以下判定は元のまま動作します。詳細は旧ガイドと同じなので割愛しますが、要点のみ：
- `js/openclose.js:92-109` が `#menubar_hdr` のクリックで `#menubar-s` の表示を切り替えます。
- **JSはページ再読み込みをしないと反映されません**（CSSはリアルタイム、JSはロード時の幅で固定）。
- ハンバーガーアイコンの見た目は `css/style.css:665,669`（`#menubar_hdr.close`/`.open`、背景画像`images/icon_menu.png`）。

### 3-4. スタッフ表示パターンの選定について（判断メモ）
旧`staff.html`には「個別プロフィール型（`id="nihon"`等、3名、写真＋名前＋紹介文の`.box`スタイル）」と「カードグリッド型（横並び6名、名前・写真ともにダミーのみ）」の2パターンが並存していました。今回は**個別プロフィール型を採用**しています。理由は、`#service`内の医師出勤表（`index.html:150-186`）が `href="#okinawa"` のように特定のスタッフ個人へリンクしており、個別プロフィール型なら名前入りの実在アンカーとして機能しますが、カードグリッド型は名前が全て「名前を入れます」のダミーで出勤表とのひも付けができないためです。カードグリッド型のHTMLは削除済みです。もし将来的にスタッフ数が増えて横並びカードにしたい場合は、`.list`クラス（`css/style.css:257-312`、480px以下は`css/style.css:806-847`）が引き続き利用可能です。

## 7. その他このテンプレート特有の仕組み

- **装飾「kazari（飾り）」オーバーレイ画像**: `123_kazari1.png`／`123s_kazari1.png`は写真の上に重ねる装飾で、クリック等の機能はない完全な静的装飾です（詳細は5章）。
- **FAQは JSアコーディオンではない**: `#faq`は`<dl class="faq"><dt>質問</dt><dd>回答</dd>...</dl>`の構造で、質問・回答は常に両方表示されたままです（開閉JSは存在しません）。アコーディオン化したい場合はJSを新規実装する必要があります。
- **CSSのみのスライドショー**: JSライブラリ不使用、`css/slide.css`の`@keyframes`のみで実装。変更なし。
- **固定（sticky）メニュー・PAGE TOPボタン**: メインメニュー自体は追従しません。追従するのは右下の「↑ PAGE TOP」ボタンのみで、`js/fixmenu_pagetop.js`がスクロール量に応じて`<body>`に`is-fixed-pagetop`クラスを付け外しします（しきい値`offsettop = 350`、`fixmenu_pagetop.js:34`）。
- **お問い合わせは電話＋LINEのみに一本化**: 旧テンプレートにあった「静的見本フォーム」と「PHP実働フォーム」の二重構造・運用方針の悩みは解消されています（4-4章参照）。もしフォーム式の問い合わせも追加したい場合は、Googleフォームなど外部サービスへのリンク／埋め込みを`#contact`セクション内に追加するのが簡単です。
- **単一ページ化による構造上の変更点**:
  - ページ内リンクは全て`href="#セクションID"`形式のアンカーに統一（旧テンプレートの別ファイルへの`href="xxx.html"`は「ホーム」以外全廃）。
  - 旧テンプレートの「共通includeが存在しない（13ファイルへの直接コピペ）」という問題点は、そもそも1ファイルになったことで実質的に解消されています。
  - `base/`フォルダ（デザイン制作用の元データ、`1_btn.png`等）は本改修では触れていません。従来通りロゴや電話バナーの自作用に利用し、使い終えたら削除して構いません。
