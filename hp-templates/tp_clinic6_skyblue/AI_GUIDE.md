# AI_GUIDE.md — tp_clinic6_skyblue 編集ガイド

このファイルは、`tp_clinic6_skyblue` テンプレート（Template Party配布の病院・歯科医院（クリニック）サイト向け無料ホームページテンプレート「tp_clinic6」のスカイブルー配色版）を、実在するクリニックの本番サイトに仕立て直すための作業ガイドです。将来このディレクトリを触るAI、または非エンジニアのサイト運営者が、コードベース全体を読み直さなくても編集できるように、実際のファイル・行・クラス名を根拠に書いています。

このプロジェクトはTemplate Partyの有償ライセンスを取得済みのため、必須クレジット表記および「ご利用前にお読みください」的な販促ブロック（`<section class="blur">`で index.html に埋め込まれていたもの）はすでに全HTMLから削除済みです。また `images/` フォルダ内のサンプル写真・ロゴ画像もすべて削除済み（フォルダ自体は空の状態で維持）で、実際のクリニック写真を後から配置する前提になっています。削除された画像の一覧と参照箇所は `_removed_images_manifest.md` にまとめられています。

このテンプレートには専用のマニュアル/しおりHTMLファイルは存在しません。`about.html` が実質的な「テンプレートの使い方」解説ページとして機能していますが、独立した readme.html のようなファイルはないので探さないでください。

## 1. 概要

`tp_clinic6_skyblue` は、**14枚のHTMLファイルからなる複数ページ構成**の病院・クリニック向けテンプレートです。全ページ共通のヘッダー（ロゴ＋バナー＋電話番号＋文字サイズ変更ボタン）、上部固定（sticky）のグローバルナビ、2カラムのメイン＋サブコンテンツ構成、共通フッター（住所・診療時間表・Googleマップ・フッターメニュー・コピーライト）を持つ、いわゆる「病院系テンプレートの定番レイアウト」です。

配色はCSSカスタムプロパティで一元管理されており、メインカラー（`--primary-color`）が **`#4ba3fc`（スカイブルー）** に設定されているのがこの「skyblue」バリエーションの特徴です。フォントは Google Fonts の「M PLUS 1」、アイコンは Font Awesome 6、トップページのメインビジュアルは自前JSによる背景フェードスライドショー、ページ下部のサムネイル一覧は slick.js を使ったスライドショーです。

サイト全体にわたって、スクロールで要素がふわっと出現する「inview」アニメーション（`blur`, `up`, `down`, `transform1〜3`）が多用されています。

## 3. メニュー（ナビゲーション）の編集方法

- **メインナビのHTML本体**：各HTMLファイルの `<div id="menubar"><nav><ul>...</ul></nav></div>` ブロック（`index.html` では45〜71行目）。全14ページに同一のマークアップがコピーされているため、**メニュー項目を追加・削除・リネームする際は14ファイル全部を同じように直す必要があります**（このテンプレートにはインクルード機構がありません）。
- **ドロップダウンメニューの作り方**：親となる `<li>` の**中に**サブメニュー用の `<ul>` をそのままネストします（`about.html` 154〜176行目に「OKな例／NGな例」の解説あり）。
  ```html
  <li><a href="">親となるメニュー</a>
      <ul>
      <li><a href="list.html">ドロップダウンのメニュー</a></li>
      </ul>
  </li>
  ```
  親`<li>`の外に`<ul>`を置くと動作しません。
- **サブメニュー（右カラムの`.sub-contents nav`）と フッターメニュー（`#footermenu`）** も各ページ末尾に同じ内容が個別にハードコードされているので、メインナビを変えたらこちらも14ファイル分揃えて直す必要があります。
- **レスポンシブの切り替えブレイクポイント**：`js/main.js` 29行目
  ```js
  if(window.innerWidth <= 900) {	// ここがブレイクポイント指定箇所です
  ```
  この900px以下でハンバーガーメニュー（開閉式）に切り替わります。数値を変える場合はこの1箇所のみでOK（全ページ共通の外部JSのため）。
- **ボタン風メニュー項目**：メインナビ自体に「強調ボタン」用の特別なクラスはありません。ただしトップページのヒーロー画像下にある予約導線 `ul.mainimg-btn`（`index.html` 94〜97行目、WEB予約/電話予約の2ボタン）が視覚的にCTAボタンとして機能しており、リンク先の `#` を実際の予約システムURL・`tel:`リンクに差し替える必要があります。
- **開閉に関わる重要なブロック**：`<div id="trigger-point">`（各ページ15〜42行目、ヘッダー全体を囲む）は、スクロールでメニューが上部固定（sticky→fixed）になる判定に使われる不可視のトリガー要素です。誤って削除しないよう`about.html`178〜185行目でも注意喚起されています。

## 4. テキスト・コンテンツの編集箇所

- **`<title>`タグ**：全14ページで
  ```
  <title>病院・歯科医院（クリニック）サイト向け 無料ホームページテンプレート tp_clinic6</title>
  ```
  のまま（`grep -n "<title>" *.html` で確認済み、全ページ同一）。ページごとに実際のクリニック名／ページ名を入れたタイトルへ個別に書き換える必要があります。
- **`<meta name="description">`**：全14ページで `"ここにサイト説明"` または `"ここにサイト説明を入れます"` のプレースホルダーのまま（`grep -n 'meta name="description"' *.html` で確認済み）。ページごとの内容説明文に差し替え。
- **h1ロゴのalt属性**：各ページ19行目付近
  ```html
  <h1 id="logo"><a href="index.html"><img src="images/logo.png" alt="東京横浜サンプル医院"></a></h1>
  ```
  `alt="東京横浜サンプル医院"` の部分を実クリニック名に変更（全14ファイルで置換が必要）。フッターの `images/logo_footer.png` の alt（index.htmlのみ、311行目）も同様に変更。
- **コピーライト表記**：各ページ末尾の `<footer>` 内
  ```html
  <small>Copyright&copy; <a href="index.html">東京横浜サンプル医院</a> All Rights Reserved.</small>
  ```
  「東京横浜サンプル医院」を実クリニック名に置換（全14ファイル共通）。
- **住所・電話番号・受付時間**：各ページのヘッダー（`03-0000-0000` / `受付時間：AM9:00〜PM7:00`）とフッター左カラム（`〒000-0000 東京足立区XXXXXX1丁目1号` / `代表電話：000-0000-0000` / `受付時間：月曜日から金曜日の8時から18時まで`）に全ページ共通で埋め込まれているダミー値。実データへ一括置換が必要。
- **「サンプルテキスト」が残っているファイル**（`grep -l "サンプルテキスト" *.html` で検出）：
  `access.html`、`index.html`（お知らせ欄）、`info.html`、`service.html`、`faq.html`、`recruit.html`、`about.html`、`staff.html` — 上記8ファイルにダミー本文が残っています。特に`index.html`の「お知らせ」ブロックには日付が `20XX/00/00` のままの項目が4件残っています（`grep -l "20XX/00/00" *.html` でindex.htmlのみ検出）。実際のお知らせ内容・日付に差し替えるか、不要な項目は削除してください。
- **医師出勤表・スタッフ名のダミー人名**：`index.html`の「医師出勤表」テーブルと`staff.html`には「日本太郎」「沖縄次郎」「東京花子」というダミー氏名が使われ、`staff.html`側の `id="nihon"` / `id="okinawa"` / `id="tokyo"` というアンカーIDと対応しています。氏名を変える場合、`index.html`側のリンク（`staff.html#okinawa`等）と`staff.html`側の`id`属性の対応が崩れないよう両方同時に直してください。

## 6. 配色・フォントサイズの調整方法

- **色の一括管理**：`css/style.css` 24〜30行目の `:root` ブロック
  ```css
  :root {
      --primary-color: #4ba3fc;          /*テンプレートのメインまたはアクセントとなる色*/
      --primary-inverse-color: #fff;     /*primary-colorの対として使う色*/
      --global-space: 5vw;   /*サイト内の余白の一括管理用。画面幅100%＝100vwです。*/
  }
  ```
  `--primary-color`（現在はスカイブルー `#4ba3fc`）を変えるだけで、ナビの背景色、電話番号の文字色、h2見出しの下線、FAQのアイコン色、ボタン背景、お知らせの「重要」アイコン背景など、サイト全体のアクセントカラーが一括で変わります。`--primary-inverse-color`はその上に乗る文字色（現状白）、`--global-space`は左右の共通余白幅です。
- **文字サイズ変更ボタン（「小」「大」）の実際のサイズ**：`css/style.css` 96〜103行目
  ```css
  html.f-large { font-size: 24px; }  /*「大」ボタンを押した時の文字サイズ*/
  html.f-small { font-size: 17px; }  /*「小」ボタンを押した時の文字サイズ*/
  ```
- **デフォルトをどちらにするか**：`js/fontSizeChanger.js` 15行目
  ```js
  changeFontSize('#f-small', 'f-small');	// デフォルト設定。「大」をデフォルトにしたい場合は('#f-large', 'f-large')に変更して下さい。
  ```
  現状は「小」がデフォルト。選択状態は `sessionStorage`（キー`CHSIZE`）に保存されます。
- 900px以下の画面では文字サイズ変更ボタン自体が非表示になります（`css/style.css` 284〜292行目）。

## 7. その他このテンプレート特有の仕組み

- **trigger-point + IntersectionObserver によるメニュー固定処理**（`js/main.js` 268〜363行目）：ナビが画面上端に到達すると`#menubar`に`fixed`クラス（透明度変化）→ 一定時間（`IDLE_MS=900ms`）静止していたら`fixed2`クラス（メニューの上下パディング縮小）が付与される2段階方式。index.htmlのお知らせ欄に「2025/10/31：メニューが画面上部に到達した際、数ピクセルの範囲で止めるとバウンドを繰り返すのを修正。js/main.jsのみ更新。」という更新履歴があり、この部分が最近手直しされたことが分かります。誤って`#trigger-point`ブロックを消すと固定メニューの判定自体が壊れます。
- **ページトップ（pagetop）ボタン**：`.pagetop`（各ページ末尾、上向き矢印アイコン）。スクロール量300px以上で表示（`js/main.js` 152〜158行目）。
- **ハンバーガーメニューと本文スクロールロック**：`#menubar_hdr`クリックで`.ham`クラストグル。開いている間は`MutationObserver`で`<body>`のスクロールを禁止する処理あり（`js/main.js` 117〜141行目）。
- **アンカーリンクのスムーススクロール**：固定ナビの高さぶんオフセットを引いてスクロール位置を調整する`smoothScroll()`関数あり（`js/main.js` 147〜203行目）。`info.html`の`#link1`〜`#link3`や`staff.html`の`#nihon`等はこの仕組みで動作します。
- **inviewアニメーション（scroll-in-view）**：`css/inview.css` と `js/jquery.inview_set.js` の組み合わせで、要素に `up` / `down` / `transform1` / `transform2` / `transform3` / `blur` のクラスを付けるだけでスクロール出現アニメーションが付きます。使い方の実例は `sample_inview.html` に一式まとまっています（第2章参照）。新規ページでこの効果を使う場合は、`<script src="...jquery.inview.min.js">` と `js/jquery.inview_set.js` の読み込みタグをコピーする必要があります（読み込みがないと動作しません）。
- **ヒーロースライドショーは自作JS、`js/slick.js`内の`.mainimg-slick`設定は未使用**：`index.html`のトップスライドショー（`#mainimg .slide`）は`js/main.js`末尾の`setInterval`（5000ms間隔、249〜262行目）で動いており、slickライブラリは使われていません。一方`js/slick.js`4〜9行目には`$('.mainimg-slick').slick({...})`という設定が残っていますが、**`mainimg-slick`というクラスはどのHTMLにも存在しません**（`grep`で確認済み）。事実上のデッドコードなので、触っても影響はありませんが、混乱の元になるので把握しておいてください。実際にslickが使われているのはページ下部の横スクロール式サムネイルギャラリー（`.thumbnail-slide`、`js/slick.js` 12〜31行目の設定）のみです。
- **Font Awesome 6 / Google Fonts（M PLUS 1）/ slick.css はすべてCDN経由の`@import`**（`css/style.css` 4〜14行目）。長期運用でCDNのバージョンが古くなり動作しなくなった場合は、このURLのバージョン番号を更新する必要があります（`about.html` 138〜141行目に同様の注意書きあり）。
- **診療科目詳細ページは複製前提の設計**：`service2.html`は「必要に応じてhtmlを複製して下さい」という案内文を含む雛形ページで、現状メインナビのドロップダウン3項目（一般内科／小児科／皮膚科）はすべて同じ`service2.html`を指しています。実運用では複製して科ごとに別ファイルへ分ける想定です。
