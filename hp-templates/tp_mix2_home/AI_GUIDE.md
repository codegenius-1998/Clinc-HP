## 1. 概要

`tp_mix2_home` は、現在は **`index.html` 1ファイルに全コンテンツが収まる単一ページ（LP）構成**です。

- `<title>` タグに明記されている通り、このテンプレートは本来 **「老人ホーム・介護施設・デイサービス向け」（elderly care homes / nursing care facilities / day service）** をターゲットに作られたテンプレートです。一般的な「クリニック（外来診療）向け」テンプレートではありません。
- 今回のプロジェクトでは、この介護施設向けテンプレートを**医療・クリニック向けの単一ページLP**に転用しています。今回のパスで、明らかに介護施設特有だった表現の一部を医療機関向けに書き換え済みです（書き換え箇所は4章末尾を参照）。ただし**全文の書き換えは行っていません**。ダミー文（「サンプルテキスト」等）や、書き換えると文脈が壊れる可能性がある表現はあえてそのまま残してあるので、公開前に必ず本文全体を通し読みして最終チェックしてください。
- 全体の visual style: 明朝体（Noto Serif JP）+ 英語アクセントフォント（Jost）を使った、優しく落ち着いた雰囲気。配色は緑がかったカーキ系のプライマリカラー（`#869a4d`）とオレンジ系のアクセントカラー（`#e58e3d`）、暖色系のこげ茶（`#472c1d`）を反転色として使う、柔らかい印象のトーン。CSSカスタムプロパティで一括管理されています（詳細は6章）。
- 技術構成: 素のHTML+CSS（`css/style.css` が本体、`css/theme.css` で配色・フォント変数、`css/inview.css` でスクロールアニメーション定義）、jQuery（CDN経由）+ 自前JS（`js/main.js`、`js/jquery.inview_set.js`）。ビルドツールなし、静的サイトとしてそのままアップロードして使うタイプです。

## 3. メニュー（ナビゲーション）の編集方法

- ナビゲーションHTML本体は `index.html` の `<header>` 内、`<div id="menubar">` → `<nav><ul>` の中にあります（24〜31行目付近）。フッターにも同じ項目のメニュー（`<ul class="menu">`）があるので、**メニュー項目を追加・削除・改名する場合はヘッダー側とフッター側の両方**を修正してください（1ファイルなので複数ページへの反映作業は不要になりました）。
- 現在の項目（フラットなアンカーリストに変更済み。旧「サービス」のドロップダウン子メニューは廃止）: ホーム（`#`） / 施設のご案内（`#info`） / サービス（`#service`） / よくある質問（`#faq`） / アクセス（`#access`） / お問い合わせ（`#contact`）。
- ホーム（ロゴ含む）のリンク先は `href="#"` にしてあります。これは`js/main.js`の`.pagetop`と同じ「ページ最上部へスムーススクロール」処理が`href="#"`に対して自動的に効くためです（271〜300行目 `smoothScroll()` 参照）。
- **ドロップダウンについて**: `initDropdown()`（`js/main.js`）は `<li>` の中に `<ul>` がネストされていると自動でドロップダウン扱いにする仕組み自体は残っていますが、現在のナビゲーションはどの`<li>`も`<ul>`をネストしていないフラット構成のため、実質的に発火しません。将来また子メニューを増やしたくなった場合は、`<li>`内に`<ul>`をネストするだけで自動対応します（機能自体は削除していません）。
- **レスポンシブ切り替えのブレイクポイント**: `js/main.js` 11行目 `const breakPoint = 900;` — 画面幅900px未満でハンバーガーメニュー（開閉式）に切り替わります（変更なし、旧ガイドから再確認済み）。CSS側は`css/style.css`の`.large-screen` / `.small-screen`クラスで大小画面のスタイルを分岐しています。
- **ボタン風メニュー項目のクラス**: `css/style.css` 246〜254行目付近に `.small-screen #menubar .btn a` というルールがあります。モバイル(開閉)メニュー内で `<li class="btn">` を付けたメニュー項目はアクセントカラーの目立つボタンスタイルになります（現状未使用、必要なら「お問い合わせ」に付与すると目立たせられます）。
- CSS側のメニュー関連ブロックは `css/style.css` 内で `#menubar` で検索すると一括で見つかります。

## 6. 配色・フォントサイズの調整方法

配色とフォントは `css/theme.css` の `:root { ... }` ブロックでCSSカスタムプロパティとして一括管理されています（実ファイルを再確認済み・16〜45行目）。

```css
:root {

	--bg-color: #fff;					/*主にテンプレートの背景色*/
	--bg-border-color: #ccc;			/*枠線の色*/
	--bg-inverse-color: #472c1d;		/*上のカラーの「対」として使う色*/
	--bg-inverse-border-color: rgba(255,255,255,0.5);	/*枠線の色*/

	--primary-color: #869a4d;			/*メインカラー*/
	--primary-inverse-color: #fff;		/*上のカラーの「対」として使う色*/
	--primary-border-color: rgba(255,255,255,0.5);	/*枠線の色*/

	--primary-light-color: #efefdf;		/*薄いカラー*/
	--primary-light-inverse-color: #472c1d;	/*上のカラーの「対」として使う色*/
	--primary-light-border-color: rgba(0,0,0,0.2);	/*枠線の色*/

	--light-color: #f9f6ef;			/*薄いカラー*/
	--light-inverse-color: #472c1d;		/*上のカラーの「対」として使う色*/
	--light-border-color: rgba(0,0,0,0.2);	/*枠線の色*/

	--accent-color: #e58e3d;			/*アクセントカラー*/
	--accent-inverse-color: #fff;			/*上のカラーの「対」として使う色*/
	--accent-border-color: rgba(255,255,255,0.5);	/*枠線の色*/

	--content-space-l: 5vw;		/*余白の一括管理用（画面幅に対する可変余白）*/
	--content-space-s: 2rem;	/*余白の一括管理用（文字サイズ基準の余白）*/

	--base-font: "Noto Serif JP", "Hiragino Mincho Pro", "ヒラギノ明朝 Pro W3", "HGS明朝E", "ＭＳ Ｐ明朝", "MS PMincho", serif;
	--accent-font: "Jost";

}
```

- 各色には「本体色」と「`-inverse-color`（対になる文字色/背景色）」「`-border-color`（枠線用の半透明色）」がセットで用意されています。色を変える際はinverse色とのコントラストも必ず確認すること（医療系サイトはアクセシビリティ配慮が重要）。
- フォントは `--base-font`（本文用、明朝体）と `--accent-font`（英語ロゴ・見出し補助テキスト用、Jost）の2種類。Google Fonts経由で読み込み（`theme.css` 6〜7行目の`@import`）。
- **基本フォントサイズ**: `css/style.css` 30行目、`html { font-size: clamp(13px, 0.29vw + 11.9px, 16px); }` — 画面幅375px〜1400pxの間で13px〜16pxに滑らかに可変。文字を大きくしたい場合はこの`clamp()`の最小値・最大値を引き上げるのが効果的。
- Font Awesomeのバージョンは `css/theme.css` 11行目の `@import url("https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/css/all.min.css");` で固定（6.5.2、CDN読み込み済み）。`#contact`の電話・LINEボタンで使っている`fa-solid fa-phone`・`fa-brands fa-line`アイコンもこのCDNから提供されています。

## 7. その他このテンプレート特有の仕組み

- **背景画像ブロック（`#greetings` / `#contact`）**: `bg1.webp` / `bg2.webp` を使うセクション背景の仕組み（5章参照）。`.bg-parts` / `.bg1-parts` / `.bg1-primary-light-parts` / `.bg1-light-parts` といった「背景色だけを一括で変える」ための共通クラスも `css/style.css` 1290行目以降に用意されています。`#greetings`は`class="bg-parts bg1-light-parts mt0"`、`#contact`は`class="bg-parts bg1-light-parts mb0"`のように、背景画像用の`id`と背景色用の`class`を併用しています。連続する背景セクション同士は`.bg-parts + .bg-parts`のCSSルールで隙間が自動的に詰まる設計です。
- **inview（スクロールで下からふわっと出現するアニメーション）**: `css/inview.css`にエフェクト定義（`up` / `down` / `transform1` / `transform2` / `transform3` / `blur`の6種類）、`js/jquery.inview_set.js`が制御スクリプトです。HTML側で`class="inview"`を付けた要素に自動適用されます。全体のデフォルト効果を変えたい場合は`js/jquery.inview_set.js` 6行目の`const FX_DEFAULT = 'up';`を書き換えるだけで一括変更可能。
- **横スライドするサムネイル帯（`.slideimg2`）**: 画像は必ず「4枚以上」かつ「偶数枚」で配置する仕様。左右どちら向きに流れるかは`class="img rtl"`（右→左）/`class="img ltr"`（左→右）で切り替え。速度は`js/main.js` 519行目付近`var animationTime = (divCount / 4) * 40 + 's';`の`40`の数値を大きくするほど遅くなります。
- **メインスライドショー（Ken Burns風ズーム演出）**: `js/main.js` 362〜502行目付近が制御。5秒間隔（`INTERVAL = 5000`）で自動切り替え、切り替え中に画像がゆっくり拡大するズーム演出（`transform: scale(1.07)`）付きです。フェード速度を変える場合は`css/style.css` 357行目付近`.mainimg .slide { transition: opacity 1s; }`の`1s`を変更すればJS側は自動追従します。
- **開閉式メニュー（ハンバーガー）とオーバーレイ**: `js/main.js`冒頭が制御。画面幅900px未満でハンバーガーアイコンに切り替わり、開いている間は背景に半透明オーバーレイ（`#menubar-overlay`）が出て、メニュー外クリックで閉じる仕様。
- **スムーススクロール**: `js/main.js` 217〜359行目付近。ページ内リンク（`#info`、`#service`等）と「ページトップへ戻る」ボタン（`.pagetop`）の両方に対応。固定ヘッダーではない通常タイプ（`scrollType = 'normal'`）で設定されています。単一ページ化に伴い、ナビゲーションの全リンクがこの仕組みで同一ページ内をスクロールするようになりました。
- **FAQのアコーディオン開閉**: `js/main.js` 550〜562行目付近。`.openclose`クラスの要素をクリックすると直後の要素（`dd`）が`slideToggle`で開閉し、他の開いている項目は自動的に閉じる仕様（同時に1つしか開かない）。単一ページ化後もこの仕組み・クラス名は変更していません。
- **お問い合わせ（電話＋LINE）ブロック**: `#contact`セクション内、`.contact-buttons`（`css/style.css`内、`.btn.accent a`定義の直後に新規追加）が電話・LINEボタンを横並びにするコンテナ、`.btn-tel`が電話ボタン（`--primary-color`使用）、`.btn-line`がLINEボタン（`--accent-color`使用）です。フォームは実装していません（8章参照）。ボタンの配色を変えたい場合はこのクラスをそのまま`theme.css`の色変数経由で調整できます。
- **未使用だが用意されているCSSクラス**: `.pr`（著作表示ブロック用、`css/style.css`内）は、ライセンス上の著作表示が既に削除されているため対応する`<div class="pr">`は存在しません。CSSルール自体は残っていますが実害はないので、削除せずそのままで問題ありません。

## 8. お問い合わせセクションについて（フォーム廃止・電話＋LINEのみ）

旧`contact.html`は「名前・メールアドレス・お問い合わせ内容」の3項目からなる**未接続のサンプルフォーム**でした（送信は動作しない旨の注意書きも入っていました）。今回のLP化にあたり、このフォームと注意書きは完全に削除し、代わりに`#contact`セクションを**電話＋LINEの2ボタンのみ**の構成に置き換えています。

```html
<div class="contact-buttons">
<a href="tel:0120000000" class="btn-tel"><i class="fa-solid fa-phone"></i> 電話で相談・予約する<br><span>0120-000-000</span></a>
<a href="https://lin.ee/xxxxxxx" target="_blank" class="btn-line"><i class="fa-brands fa-line"></i> LINEで相談・予約する</a>
</div>
```

- 電話番号（`tel:0120000000`と表示用`0120-000-000`の2箇所）、LINEの友だち追加URL（`https://lin.ee/xxxxxxx`）はいずれもダミー値です。公開前に必ず実際の値へ差し替えてください。
- フォームを今後追加したい場合は、別途フォームビルダーや自前のバックエンド・メールサービス連携が必要です（このテンプレートにはPHP等のフォーム処理は同梱されていません）。
