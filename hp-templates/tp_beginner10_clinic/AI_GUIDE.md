## 1. 概要

- **サイトタイプ**: **1ページ完結のランディングページ（LP）**。本番ページは `index.html` 1枚のみ＋ナビゲーションに含まれない `_manual.html`（テンプレート作者のマニュアル、非公開ページ）の合計2ファイル。
- **業種テーマ**: 病院・クリニック向け。ヘッダーの直下から順に「お知らせ」「当院について」「診療科目」「スタッフ紹介」「お問い合わせ（電話・LINE）」を1枚のページ内でスクロールして読ませる構成。電話・LINEでの問い合わせ・予約を促すことに焦点を絞ったLPです。
- **配色**: ベースは白背景＋グレー系の文字色に、テーマカラーとして青系（`#0063af`）を差し色として使用（ボタン・見出し帯など）。清潔感のある医療系らしい配色。
- **フォント**: Google Fonts「LINE Seed JP」を全体に適用（角ゴシック系、和文可読性重視）。
- **演出**: ヘッダー直下に横スライド式の画像スライドショー（自動切り替え）、各所にスクロール連動のフェードイン演出（jQuery `inview`）、900px未満でハンバーガーメニューに切り替わるレスポンシブ設計。ナビゲーションのメニューは別ページへのリンクではなく、**同じページ内の該当セクションへ飛ぶアンカーリンク**（`#about`など）になっています。
- **技術構成**: 素のHTML/CSS/JavaScript（jQuery依存）。ビルドツールやテンプレートエンジンは使用していない静的サイト。

## 3. メニュー（ナビゲーション）の編集方法

- ナビゲーションのHTMLは `index.html` の`<header>`内、16〜29行目にあります（1ページ構成になったため、複数ファイルを揃えて編集する必要はもうありません）：
  ```html
  <header>
  <h1 id="logo"><a href="index.html"><img src="images/logo.png" alt="あなたのサイト名"></a></h1>
  	<!--開閉メニュー-->
  	<div id="menubar">
  	<nav>
  	<ul>
  	<li><a href="#about">当院について</a></li>
  	<li><a href="#service">診療科目</a></li>
  	<li><a href="#staff">スタッフ紹介</a></li>
  	<li><a href="#access">アクセス</a></li>
  	<li class="btn"><a href="#contact">お問い合わせ</a></li>
  	</ul>
  	</nav>
  	</div>
  </header>
  ```
  各`<a href="#xxx">`は、ページ内の`<section id="xxx">`へジャンプするアンカーリンクです。項目名を変更する場合は`<a>`タグ内のテキストのみ変更すればOKです。項目を増やす場合は対応する`<section id="新しいID">`をページ内に用意した上で`<li><a href="#新しいID">項目名</a></li>`を追加してください。
- **ボタン風メニュー項目**: `class="btn"`が付いた`<li>`がボタン風の見た目になります。現在は**「お問い合わせ」（`#contact`へのリンク）にこのクラスを付けています**（LP化に伴い、旧テンプレートで採用情報に付いていた`class="btn"`をお問い合わせへ移動しました）。装飾を外したい／別項目に移したい場合は`class="btn"`を該当`<li>`から外す／移すだけで、見た目が通常メニューと同じになります。スタイル定義は`css/style.css`の`.btn a`ブロック（347行目付近）。
- **レスポンシブのブレイクポイント**: `js/main.js`の10行目
  ```js
  const breakPoint = 900;	// ここがブレイクポイント指定箇所です
  ```
  画面幅900px未満でハンバーガーメニュー（開閉式）に切り替わります。数値を変更すれば切り替わるタイミングを調整できます。CSS側にも`css/style.css`内に`@media screen and (min-width:900px)`の指定が複数箇所（60行目・301行目・420行目）あるため、ブレイクポイントを変更する場合はJS側の数値とCSS側のメディアクエリの数値を揃える必要があります。

## 6. 配色・フォントサイズの調整方法

このテンプレートは**CSSカスタムプロパティ（`:root`ブロック）による色管理を実際に採用しています**（`css/style.css` 23〜33行目）。

```css
:root {
	--bg-color: #fff;			/*主にテンプレートの背景色*/
	--bg-inverse-color: #333;	/*上のbg-colorの対として使う色*/
	--primary-color: #0063af;		/*テーマカラー*/
	--primary-inverse-color: #fff;	/*上のprimary-colorの対として使う色*/
	--content-space: 5vw;	/*色々な余白管理用。画面幅100% = 100vwです。*/
}
```

- `--bg-color`: サイト全体の基本背景色（白）。
- `--bg-inverse-color`: 基本の文字色、および開閉メニューの背景に対する文字色（濃いグレー）。
- `--primary-color`: テーマカラー（青、`#0063af`）。ボタン（`.btn a`、`style.css`347行目）や、新設した電話ボタン（`.btn-tel`、616行目付近）などに使用。
- `--primary-inverse-color`: テーマカラー上に乗る文字色（白）。LINEボタン（`.btn-line`）の背景色にも使用。
- `--content-space`: ページ全体の余白基準値（`5vw`）。

これらの値を変更するだけでサイト全体の配色（お問い合わせボタンを含む）が一括で変わります。ただし、`.bg1`セクション背景色（水色、`#d8e8f4`、`style.css`524行目付近）や`.ta1 caption`の背景（`rgba(0,0,0,0.1)`、388行目付近）、`.week2`テーブルの背景・枠線色など、**`:root`変数を使わず直接カラーコードがハードコードされている箇所も複数あります**。これらを変更したい場合は、該当セレクタを`style.css`内で直接検索して書き換える必要があります。

**フォントサイズ**は`style.css`の55〜66行目に基準値が2箇所あります：
```css
html,body {
	font-size: 13px;	/*基準となるフォントサイズ。*/
}
	@media screen and (min-width:900px) {
	html, body {
		font-size: 15px;	/*基準となるフォントサイズ。*/
	}
	}
```
1つ目（13px）が900px未満（スマホ等）、2つ目（15px）が900px以上（PC等）向けの基準サイズです。他の多くの要素が`rem`単位で指定されているため、この2箇所を変更するだけでサイト全体の文字サイズを一括調整できます。

## 7. その他このテンプレート特有の仕組み

- **お問い合わせは電話・LINEのみ**: 旧`contact.html`にあった動作しない（送信処理未実装の）サンプルフォームは完全に廃止しました。フォーム実装や送信処理の心配は不要になった一方、電話番号・LINE URLの設定は必須です（4-3章参照）。将来的にメールフォームを追加したい場合は、`#contact`セクションに新しいブロックとして追加するか、別途フォーム送信サービスと連携した実装が必要です。
- **診療日・アクセスは`#hours`／`#access`として復元済み**: 旧トップページにあった受付時間表とGoogleマップ埋め込みは、`#hours`（`.week2`テーブル）・`#access`（`.iframe-box1`）として`#staff`の後・`#contact`の前に配置されています。マップのiframe srcは東京都内のサンプル座標のままなので、実際のクリニック所在地の埋め込みコードに差し替えてください（Googleマップで「共有」→「地図を埋め込む」から取得）。
- **Font Awesomeアイコン**: `style.css`冒頭7行目で`@import url("https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/css/all.min.css");`によりCDN経由で読み込み。フッターSNSアイコン（`<i class="fa-brands fa-x-twitter">`等、`<footer><ul class="icons">`内）、ページ上部へ戻るボタン（`fas fa-angle-double-up`）、新設のお問い合わせボタン（`fa-solid fa-phone`／`fa-brands fa-line`）に使用。SNSアイコンのリンク先は現状すべて`href="#"`のダミーなので、実際のSNSアカウントURLに変更が必要です。使用しないSNSがあれば該当`<li>`を削除してください。CDN経由のため、数年後に動作しなくなった場合はバージョン番号（`6.5.2`）を最新版に更新することが有効です。
- **スクロール連動フェードイン演出（inview）**: `css/inview.css`と`js/jquery.inview_set.js`により、`class="up"`が付いた要素（例: `#service`セクションの診療科目カード`<div class="list up">`）が画面内にスクロールで入ると`upstyle`クラスが付与され、下から上へフェードインします。演出を無効化したい要素があれば、該当`<div>`から`class="up"`を外せばフェードインせず最初から表示された状態になります。
- **スライドショーの自動切り替え間隔**: `js/main.js`279行目の`setInterval(..., 4000)`で4秒ごとに自動切り替え。切り替えアニメーション時間（0.7秒）は`css/slide.css`19行目の`transition: transform 0.7s ease;`と`js/main.js`301行目の`700`（ミリ秒）で対になっており、**片方だけ変更すると演出がずれる**ため変更時は両方揃えること。
- **`body`要素のクラス`home`について**: `index.html`は`<body class="home">`です。`style.css`133〜135行目の`body:not(.home) #container { grid-template-rows: auto 1fr; }`により、スライドショーがあるページはグリッド行が1つ多い特別レイアウトになる仕組みですが、現在は`index.html`しか存在しないため、実質的に常に`home`クラスが付いた状態で運用されます（このクラスを外すとスライドショー分のレイアウトが崩れるため、外さないでください）。
- **アンカーリンクのスムーススクロール**: `js/main.js`197行目付近の`$('a[href^="#"], .pagetop').click(function(e) {...})`により、`#about`等のアンカーリンククリック時に滑らかにスクロールする処理が既に実装されています（1ページ化にあたり新規追加は不要でした）。
- **favicon（ブラウザタブアイコン）が未設定**: `<head>`内に`<link rel="icon">`等の記述が一切ありません。公開前にfaviconファイルを用意し、`index.html`の`<head>`に追加することを推奨します。
