## 1. 概要

`tp_clinic7_blue_LP` は、テンプレート配布サイト「Template Party（テンプレートパーティ）」由来の、歯科医院・クリニック向け**1ページ完結型（LP: ランディングページ）**無料HTMLテンプレートです。

- 実体は `index.html` 1ファイル（647行）＋補助の `_manual.html`、`css/`、`js/`、`images/`（現在は空、`movie.mp4` のみ残存）だけで構成されています。
- 配色はブルー系（メインカラー `#1f6bbe`、アクセントカラー `#2eb8cb` の水色寄りの青緑）で、清潔感・信頼感を意識した医療系デザインです。
- **LP（1ページ）が多ページサイトと違う点**: 「診療メニュー」「スタッフ紹介」「よくある質問」などのコンテンツはすべて `index.html` 内の別々の `<section>` として縦に並んでいます。ページ遷移（別ファイルへのリンク）ではなく、同一ページ内の**アンカーリンク**（`href="#section-id"` で該当セクションまでスムーススクロールする方式）でナビゲーションするのが基本設計です。ただし後述の通り、現状のテンプレートではこのアンカーリンクの配線（`id` 属性とリンク先の対応）は**まだ実装されておらず、すべて `href="#"` のプレースホルダのまま**です。本番化の際は各セクションに `id` を振り、ナビゲーションのリンク先を実際に指定し直す必要があります。
- 本テンプレートはすでに以下の作業が完了しています（このガイドの対象外）。
  - Template Partyの商用ライセンス取得済みのため、必須クレジット表記は `index.html` から削除済み。
  - もともと埋め込まれていた「ご利用前にお読みください」的な販促セクションも削除済み。
  - `images/` フォルダ内のサンプル写真・ロゴ画像はすべて削除済み（フォルダ自体は残置、`movie.mp4` のみ実データとして残存）。削除されたファイルの一覧は `_removed_images_manifest.md` を参照。

### ビフォーアフター比較の仕組み（重要）

`.list-before-after` ブロック（289-329行）は、**画像を重ねて動かすスライダーではなく**、CSS Flexboxで「Before画像・矢印アイコン・After画像」を横並び（600px以下では縦並びに変化）にするだけの静的な比較レイアウトです（`css/style.css` 1231-1341行）。

- 1ペア＝ `<div class="pair">` 1個。中に `figure.before-img` と `figure.after-img` を1つずつ、間に `<div class="arrow">` を置く。
- `before-img` 側は黒背景半透明の「Before」ラベル、`after-img` 側はメインカラー背景の「After」ラベルが `<span class="label">` として自動でCSS表示される（HTML側でラベルの文言を直接書く必要あり：`<span class="label">Before</span>` のようにテキストは書く必要がある）。
- 各画像には `figcaption` でキャプション文（症例の説明）が入る。
- 画像は `aspect-ratio: 3 / 2; object-fit: cover;` で自動トリミングされるので、極端に縦長・横長の写真を使うと重要な部分が切れる可能性がある。
- ペアを増やしたい場合は `<div class="pair">...</div>` ブロックごと複製すればよい。

現在2ペア（`before-after1-1.jpg`/`1-2.jpg` = ホワイトニング前後、`before-after2-1.jpg`/`2-2.jpg` = 矯正前後）が入っている。数字が同じ組（`1-1`と`1-2`、`2-1`と`2-2`）が1ペアで、末尾`-1`が Before、`-2`が After。

## 3. メニュー（ナビゲーション）の編集方法

このLPには2種類のナビゲーション要素があります。

1. **メインビジュアル直下の強みアイコンナビ** `.mainimg-nav`（`index.html` 53-60行）。4つの `<li><a href="#">...</a></li>` があり、現状すべて `href="#"` のプレースホルダ。強みを紹介するセクションへのアンカーリンクとして使うなら、対応する `<section>` に `id` 属性を追加し、`href="#その id"` に書き換える。
2. **ハンバーガーメニュー（開閉メニュー）** `#menubar`（`index.html` 591-618行）。中の `<nav><ul>...</ul></nav>`（602-616行）には、多ページテンプレート流用の名残で「ホーム」「ドロップダウン」（子メニュー付き）「ページ」×2 というダミー項目が入っている。LPでは実在しない `page.html` へのリンクになっているため、**本番化時は必ず**各項目を、ページ内の各セクション（診療メニュー・スタッフ紹介・アクセス等）へのアンカーリンクに書き換えること。ドロップダウンが不要なら `<li class="...">` の子`<ul>`ごと削除してよい。

**セクションに `id` を振る際の注意**: 現状 `index.html` 内の `<section>` タグには（`#popup` を除き）`id` 属性が一切付いていない（`grep -n 'id="' index.html` で確認済み）。アンカーリンクを機能させるには、まずナビゲーションで使いたい各 `<section>` に `id="menu"` や `id="staff"` のような一意のIDを追加する必要がある。

**スムーススクロールの仕組み**: `js/main.js` 217-345行目の「スムーススクロール」ブロックが `a[href^="#"]` のクリックを拾って `js/main.js` 271行目の `smoothScroll()` 関数でアニメーションスクロールする。`scrollType`変数（228行目、現在`'normal'`）を`'fixed'`にすると固定ヘッダー分のオフセット計算が有効になるが、このLPは固定ヘッダーではないため`'normal'`のままでよい。

**ブレークポイント（画面幅の切り替え基準）について**: `js/main.js` 11行目に

```js
const breakPoint = 9999;	// ここがブレイクポイント指定箇所です
```

とある。通常の多ページテンプレートでは900px前後が指定されるところ、この値が **9999** と極端に大きい。これは実質「どんな画面幅でも常にハンバーガーメニュー（開閉式）を使う」設定であり、**PC幅でも横並びの通常ナビゲーションには切り替わらない**ことを意味する（`_manual.html` 105-109行が言及している「900pxで非表示になる横並びメニュー(menubar2)」は、このLP版の `index.html` には実際には存在しない要素なので、その記述は多ページ版向けの名残であり、このLPには当てはまらない点に注意）。もしPC幅で通常の横並びメニューに切り替えたい場合は、対応する`nav`をheader内に新設しCSSを書き足す改修が必要（このテンプレートの標準機能ではない）。単に開閉メニューの見た目のまま使う場合は`breakPoint`の値を変更する必要はない。

## 6. 配色・フォントサイズの調整方法

色とフォントサイズの基本設定はすべて `css/theme.css`（54行、CSSカスタムプロパティ集約ファイル）に集約されている。

### 配色（`css/theme.css` 19-45行の `:root` ブロック）

```css
--bg-color: #fff;                              /* 主にテンプレートの背景色 */
--bg-border-color: rgba(0,0,0,0.2);
--bg-inverse-color: #333;                       /* 上の色の「対」として使う色 */
--bg-inverse-border-color: rgba(255,255,255,0.5);

--primary-color: #1f6bbe;                       /* メインカラー（青） */
--primary-inverse-color: #fff;
--primary-border-color: rgba(255,255,255,0.5);

--light-color: #f0f7fb;                         /* 薄いカラー */
--light-inverse-color: #333;
--light-border-color: rgba(0,0,0,0.2);

--accent-color: #2eb8cb;                        /* アクセントカラー（水色） */
--accent-inverse-color: #fff;
--accent-border-color: rgba(255,255,255,0.5);

--content-space-l: 5vw;                         /* 余白の一括管理用 */
--content-space-s: 2rem;

--base-font: "Noto Sans JP", "Hiragino Kaku Gothic Pro", ...;  /* 本文フォント */
--accent-font: "Jost";                          /* 英数字アクセント用フォント */
--serif-font: "Noto Serif JP";                  /* 明朝系アクセント用フォント */
```

- 変更方法: `--primary-color` を書き換えるだけで、ボタン・見出し下線・アイコン背景・「治療の流れ」の番号など、サイト全体のメインカラーが一括で変わる（`css/style.css` 側は `var(--primary-color)` の形で参照しているため）。
- `--light-color`はセクション背景の淡色（`.bg1-light-parts`等で使用）、`--accent-color`はワンポイント差し色（ボタンhoverや一部見出し）に使われる。
- 500px以下の画面では `--content-space-l` が `5vw` から `10px` に上書きされる（theme.css 47-54行の追加`@media`ブロック）。左右の余白調整はここ。

### フォントサイズ（`css/style.css` 29-32行）

```css
html {
	font-size: clamp(12px, 0.585vw + 9.80px, 18px);	/* 画面幅375px〜1400pxの間で12px〜18pxに可変 */
	overflow-x: visible;
}
```

サイト全体の `rem` 基準値がここで可変指定されている（レスポンシブ対応の可変フォント）。全体的に文字を大きく/小さくしたい場合は、この`clamp()`の最小値(12px)・最大値(18px)を調整する。個別要素の文字サイズは各セクションのCSS内で `rem`（例: `font-size: 1.4rem;`）や `vw`/`max()`/`clamp()` で指定されているため、変更したい箇所は `css/style.css` 内を該当クラス名（例: `.list-mask h4`）で検索する。

Google Fontsの読み込みは `css/theme.css` 4-9行目（Noto Sans JP, Noto Serif JP, Jost, Ballet の4書体）。Font Awesomeアイコンの読み込みは同13-14行目（CDN版6.5.2）。

## 7. その他このテンプレート特有の仕組み

- **スクロールで下からふわっと出現する演出（inview）**: `class="inview"` が付いた要素（悩みブロック、治療の流れ、スタッフ紹介、FAQ項目など多数）は、画面内に入ったタイミングで `js/jquery.inview_set.js` がフェードイン等のクラスを自動付与する。デフォルトの演出は同ファイル6行目 `const FX_DEFAULT = 'up';` で、`up`/`down`/`transform1`/`transform2`/`transform3`/`blur` の6種類から選べる（実際のスタイル定義は `css/inview.css`、120行）。特定の要素だけ別演出にしたい場合はHTML側に `data-fx="blur"` のように指定を追加する。
- **「院内・設備紹介」のサムネイル切替ビューア**（`.thumbnail-view` / `.thumbnail-changer`）: 5章で述べた通り、画像・動画混在のサムネイルをクリックすると上の大表示エリアに切り替わる仕組み。加えて `js/main.js` 428-467行で横スクロール用の矢印ナビ（`.thumb-arrow3`）が自動生成される（HTMLに矢印を書く必要はない、JSが動的に追加する）。
- **ビフォーアフター比較**: 2章で詳述の通り、スライダーではなく静的な横並び（モバイルは縦並び）比較レイアウト。
- **お客様の声の横スクロールカルーセル**（`.list-yoko-scroll`）: `scroll-snap-type: x mandatory` を使ったCSSのみのスナップスクロール実装（JS不使用）。矢印ボタン等はない、指/マウスでのドラッグスクロール前提。
- **FAQのアコーディオン開閉**: `js/main.js` 522-532行、`.openclose .q` クリックで `.faq-item` に `open` クラスをトグルし `slideToggle` で開閉する単純な仕組み。
- **右端固定の縦書きサイドボタン**（`#message`、`css/style.css` 1804-1825行）: 画面スクロール500px以降にフェード表示される「WEB予約はこちら」の常時表示CTA。`position: fixed; writing-mode: vertical-rl;` で縦書き表示。制御は `js/main.js` 535-552行。
- **ページ下部ポップアップ告知**（`#popup`、`css/style.css` 1841-1875行）: セッション中1回だけ、初回表示から3秒後にフェード表示される（`js/main.js` 555-577行、`sessionStorage`でセッション内一度きり制御）。閉じるボタンで即座に非表示。ブラウザを閉じて開き直すと再度表示される仕様。不要なら`index.html`の625-631行ブロックごと削除してよいとHTML内コメントにも明記あり。
- **メインビジュアルはPC/スマホで別画像を出し分け**（`<picture><source media="(max-width: 700px)">`使用）。同じ画像で統一したい場合はPC用・スマホ用に同じファイル名を指定すればよい。
- **ハンバーガーメニューの開閉制御は常時有効**: 3章で述べた通り `breakPoint = 9999` のため、画面幅に関わらず常にハンバーガーアイコン開閉式のメニューになる。デザイン上PCでも大きめの開閉メニューを使う設計だと理解した上で編集すること。
