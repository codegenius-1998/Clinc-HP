# AI_GUIDE.md — tp_seikotsu1_navy 改修ガイド

このファイルは、`tp_seikotsu1_navy` テンプレートを実在の整骨院・接骨院の本番ホームページへ改修する際に、AIアシスタント（または非エンジニアのサイト運営者）がコード全体を最初から読み直さなくても作業できるようにするための実務ガイドです。

前提として、このプロジェクトは元々 [Template Party](https://template-party.com/) が無料配布していたテンプレート `tp_seikotsu1` を、サイト所有者が有償ライセンス契約を結んだ上でカスタマイズしたものです。ライセンスにより本来必須だったフッターの著作表示（`Web Design:Template-Party`）は全HTMLファイルから既に削除済みです。また `images/` フォルダ内のサンプル写真・ロゴ画像はすべて削除済み（フォルダ自体は空の状態で残置、`movie.mp4` のみ現存）で、削除された画像の一覧・元サイズ・参照箇所は `tp_seikotsu1_navy/_removed_images_manifest.md` に記録されています。本ガイドはその内容も踏まえて画像復旧作業を具体的に案内します。

## 1. 概要

`tp_seikotsu1_navy` は、整骨院・接骨院（骨接ぎ／整体／柔道整復）向けに作られた**ランディングページ（LP）形式**の無料ホームページテンプレート `tp_seikotsu1` の配色バリエーション（ネイビー系）です。`_readme.html`（テンプレート作者による原本マニュアル、`<title>`に「整骨院・接骨院サイト向け ランディングページ用 無料ホームページテンプレート tp_seikotsu1」と明記）で用途が確認できます。

- **ページ数**: 3ページ構成（`index.html`＝メインのLP、`contact.html`＝問い合わせフォーム、`menu.html`＝施術メニュー一覧）＋マニュアルページ `_readme.html`。一般的な多階層サイトではなく、`index.html` 1枚に主要コンテンツをほぼ集約し、ヘッダーメニューはアンカーリンク（`#about`、`#menu`、`#flow`、`#access`）でページ内スクロールする構造です。
- **デザインテーマ**: ネイビー（濃紺）を基調にした落ち着いた配色。`css/theme.css` の `--primary-color: #101f3a;`（濃紺）が基調色で、`--accent-color: #7b8269;`（くすんだカーキ系グリーン）をアクセントに使用。和文フォントは明朝体（`Noto Serif JP`）を採用し、医療・施術系らしい信頼感のある高級感を演出しています。
- **技術構成**: 素のHTML/CSS/JS（フレームワーク不使用）。jQuery 3.6.0（CDN）、Font Awesome 6.5.2（CDN、`css/theme.css`内で読込）、Google Fonts（`Noto Serif JP` / `Jost`）、独自のスクロールイン演出用ライブラリ `jquery.inview`（CDN）＋ `js/jquery.inview_set.js`。

## 3. メニュー（ナビゲーション）の編集方法

このテンプレートのメニューは**2箇所**に分かれて実装されています（`_readme.html`113〜120行目の説明を踏襲）。

1. **PC表示用ヘッダーメニュー**：各HTMLの `<header class="site-header" id="header">` 内、`<nav>`〜`</nav>`（例：`index.html`19〜33行目）。画面幅が `1000px` 以上のときに表示される。対応CSSは `css/style.css` の `header nav`（141行目〜）ブロック。
2. **開閉メニュー（ハンバーガーメニュー）**：各HTML末尾付近の `<div id="menubar">`〜`</div>`（例：`index.html`530〜551行目）。画面幅 `1000px` 未満のときにハンバーガーアイコン（`#menubar_hdr`）をタップすると開閉する。対応CSSは `css/style.css` の `#menubar`（206行目〜、正確には`.small-screen #menubar`セレクタ群）。

**両方とも中身（メニュー項目）は同じ内容で個別に記述されているため、メニュー項目を追加・変更する場合は必ずヘッダー側と`#menubar`側の両方を編集する。** さらに3ページ（`index.html`／`contact.html`／`menu.html`）すべてに同じメニューHTMLが個別コピーされているため、リンク文言や項目を変える場合は4ファイル×2箇所＝**計8箇所**（`_readme.html`を除く3ページ×ヘッダー1＋`#menubar`1）を揃えて修正する必要がある。

**ブレークポイントの変更**：`js/main.js` 11行目に
```js
const breakPoint = 1000;	// ここがブレイクポイント指定箇所です
```
とあり、値は確認済みで **`1000`（px）**。この数値を変えるとPC表示⇔スマホ開閉メニュー表示の切り替わる画面幅が変わる（CSS側のメディアクエリと連動していないため、変更時はCSS側の`700px`/`800px`等の個別ブレークポイントとは別物である点に注意）。

**リンク先の違いに注意**：`index.html`内のヘッダー/メニューは`#about`のようにページ内アンカーで直接指定しているが、`contact.html`・`menu.html`では`index.html#about`のように別ページからトップページの該当セクションへ戻るリンクになっている。ページを追加した場合はこのパターンに倣うこと。

## 6. 配色・フォントサイズの調整方法

### 6-1. 配色（`css/theme.css`）

`css/theme.css` の `:root { }` ブロック（16〜41行目）にCSSカスタムプロパティとして色・余白・フォントが一括管理されています。実際の宣言内容は以下の通り（コメントは原文ママ）。

```css
:root {
	--bg-color: #fff;                                  /*主にテンプレートの背景色*/
	--bg-border-color: #ddd;                           /*枠線の色*/
	--bg-inverse-color: #101f3a;                        /*上のカラーの「対」として使う色*/
	--bg-inverse-border-color: rgba(255,255,255,0.5);   /*枠線の色*/

	--primary-color: #101f3a;                           /*メインカラー（ネイビー）*/
	--primary-inverse-color: #fff;                       /*上のカラーの「対」として使う色*/
	--primary-border-color: rgba(255,255,255,0.5);       /*枠線の色*/

	--light-color: #f2f5f9;                              /*薄いカラー*/
	--light-inverse-color: #101f3a;                       /*上のカラーの「対」として使う色*/
	--light-border-color: rgba(0,0,0,0.2);                /*枠線の色*/

	--accent-color: #7b8269;                             /*アクセントカラー（くすみグリーン）*/
	--accent-inverse-color: #fff;                         /*上のカラーの「対」として使う色*/
	--accent-border-color: rgba(255,255,255,0.5);         /*枠線の色*/

	--content-space-l: 7vw;      /*余白の一括管理用。画面幅100% = 100vwです。*/
	--content-space-s: 2rem;     /*余白の一括管理用。2文字分。*/

	--base-font: "Noto Serif JP", "Hiragino Mincho Pro", "ヒラギノ明朝 Pro W3", "HGS明朝E", "ＭＳ Ｐ明朝", "MS PMincho", serif;
	--accent-font: "Jost";
}
```

- 配色を丸ごと変えたい場合は `--primary-color`（基調のネイビー）、`--light-color`（淡色）、`--accent-color`（アクセント）の3色を変更するのが最も効率的（`_readme.html`54〜58行目でも同様の3色セットとして案内されている）。それぞれ「反転色」（`-inverse-color`）と「枠線色」（`-border-color`）が対になっているため、色を変える際はセットで見直すこと。
- Google Fontsの読込は`theme.css`4〜7行目（`Noto Serif JP`＝和文明朝体、`Jost`＝英字装飾フォント）。フォント自体を変更する場合はこの`@import`のURLと`--base-font`/`--accent-font`変数の両方を編集する。
- Font Awesomeアイコンフォントの読込も`theme.css`9〜11行目（CDN、バージョン6.5.2）。

### 6-2. 基本フォントサイズ（`css/style.css`）

- ルートのフォントサイズは `css/style.css` 29〜31行目：
```css
html {
	font-size: clamp(13px, 0.29vw + 11.9px, 16px);	/*画面幅375px〜1400pxの間で、13px〜16pxに可変*/
}
```
画面幅375px〜1400pxの間でルートフォントサイズが13px〜16pxへ滑らかに変化する`clamp()`指定。サイト全体の`rem`指定はこの値を基準に連動する。全体的に文字を大きく/小さくしたい場合はこの`clamp()`の最小値・最大値を調整する。
- 個別要素のフォントサイズはほぼ全て`rem`または`em`の相対指定（例：`.mainimg .text h2`は`font-size: max(15px, 3vw);`、`.small`クラスは`font-size: 0.85em;`、`.large`クラスは`font-size: 1.6em;`）。`css/style.css`末尾1702〜1703行目に汎用ユーティリティクラス`.small`/`.large`が定義されている。

## 7. その他このテンプレート特有の仕組み

- **スクロールイン演出（inview）**：`class="inview"`が付与された要素（例：お悩みカード、当院についてのテキスト・画像、施術メニューカードなど、ほぼ全セクションに多用）は、画面内にスクロールして入ったタイミングでふわっと出現するアニメーションが適用される。制御は `js/jquery.inview_set.js`。冒頭6行目
```js
const FX_DEFAULT = 'up';	// data-fx が無い時のデフォルト
```
のデフォルト効果は`up`（下からふわっと）。選べる効果は`up`/`down`/`transform1`/`transform2`/`transform3`/`blur`の6種（10行目`FX_LIST`）。個別要素だけ演出を変えたい場合はHTML側に`data-fx="blur"`のように指定する。対応スタイルは `css/inview.css`（別ファイル、`style.css`7行目で`@import`）に120行分定義されている。
- **お客様の声カルーセル**：`.list-auto1`（口コミ枠）は`js/main.js`の「サムネイルの横スライドショー」ロジック（351〜553行目）で自動スライド（`autoSlideInterval = 4000`ミリ秒間隔）する。画面幅801px以上では4件ずつ／2件送り、800px以下では2件ずつ／1件送りで表示（389〜397行目）。カード枚数が表示枚数以下の場合は自動的にスライド機能自体をOFFにする実装（400〜406行目）なので、口コミ件数を減らしても表示は破綻しない。
- **ヘッダーの自動フェード（隠れるヘッダー）**：`js/main.js`末尾付近（560〜586行目）に、下スクロールでヘッダーを隠し、上に少し戻すと再表示する処理がある。`startPos = 150`（px、隠し始める位置）、`tolerance = 10`（px、戻し判定の遊び）の2変数で挙動を調整可能。対応CSSは`css/style.css`114行目`.site-header.is-hide`。
- **開閉式ハンバーガーメニュー＋オーバーレイ**：`js/main.js`冒頭（1〜214行目）が担当。`#menubar-overlay`をクリックするとメニュー外クリックとして閉じる仕組み、`HIDE_MENUBAR_IF_HDR_HIDDEN`（16行目、既定`true`）でPC表示時に`#menubar`自体を隠すかどうかを切替可能。ヘッダーメニュー側にもドロップダウン初期化（`initDropdown($('header nav'), ...)`、213行目）が別途適用されており、PC幅では`hover`、スマホ幅では`click`でドロップダウンが開く仕様。
- **スムーススクロール**：`js/main.js`217〜345行目。`scrollType = 'normal'`（228行目、固定ヘッダーではない設定）。`#`始まりのリンク（アンカーリンク）は自動的にスムーズスクロール対象になる。ハッシュ付きURLで直接アクセスした場合も0.5秒後にスクロール位置を補正する処理あり（337〜343行目）。
- **FAQのアコーディオン開閉**：`js/main.js`末尾（592〜599行目）の汎用処理。`.openclose`をクリックすると次の要素（`<dd>`）が`slideToggle`し、他の開いている項目は自動的に閉じる（同時に1つしか開かない仕様）。
- **レスポンシブ用の別画像指定（`<picture>`/`srcset`）**：メインビジュアルのみ、画面幅800px以下で専用の軽量画像（`mainimg1_s.jpg`）に切り替わる`<picture>`要素を使用（`index.html:49`）。他のセクションの画像は単一の`<img>`のみで、レスポンシブ時の解像度切替は行っていない。
- **未使用リンク（`classes1.html`〜`classes3.html`）に関する注意**：「お悩み」セクション（onayami1〜4）と「施術の流れ」セクション（flow1〜4）の画像はいずれも`<a href="classes1.html">`のように、このテンプレートセットに含まれていない`classes1.html`／`classes2.html`／`classes3.html`という架空のページへリンクしている（`index.html`66,74,82,90,225,233,241,249行目）。公開前に、詳細ページを新設してリンク先を差し替えるか、リンクを`#`やアンカー内リンクに変更するか、あるいは`<a>`タグ自体を外す対応が必要。
- **`menu.html`のメニュー項目重複**：2-3章で述べた通り、`menu.html`は同じ4項目を2回（計8ブロック）繰り返して掲載している。実運用ではメニュー項目数に応じて調整する。
