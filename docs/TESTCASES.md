## 0. この文書について

### なぜ必要か

このシステムは**役割が2つ（クリニックオーナー／管理者）**あり、権限の境界・AIを使う長時間処理・外部サービス（OpenAI／Supabase Storage／Cloudflare D1）への依存が絡み合っています。

直近だけでも、次の不具合が**実際に画面を操作して初めて**発覚しました。

| 発覚した不具合 | 見つかった経緯 |
|---|---|
| サイト作成が4分かかり、Cloudflareの100秒制限で毎回接続が切れる | 作成ボタンを押して待った |
| 作り直すとDBのUNIQUE制約で**最後に必ず**失敗する（課金だけ発生） | 2回目の作成を試した |
| iPhone写真（HEIC）がアップロードは通るのに取り込みで弾かれる | 実際に画像を上げた |
| 診療時間が全角スペース区切りだと表が崩れる | 実データで確認した |

いずれも**コードを読むだけでは分からない**種類のものです。画面を一通り触る手順を決めておかないと、同じ見落としが繰り返されます。

### 記法

| 記号 | 意味 |
|---|---|
| 🔴 | **必須**。これが落ちたらリリース不可 |
| 🟡 | 重要。変更のたびに流す |
| ⚪ | 余裕があれば |
| 💰 | **OpenAIの課金が発生する** |
| ⏱ | 数分かかる |

### 検証状況について

⚠️ このテストケースのうち、**ログインを要するケースは未検証**です（作成者がアカウントにログインできないため）。ログイン不要の範囲（文言・権限拒否・SP表示・404）は実機で確認済みです。各章の冒頭に検証状況を記載しています。

## 1. 事前準備

| # | 準備するもの | 理由 |
|---|---|---|
| 1 | サーバー起動（`npm run build` → `npm start`） | 本番ビルドで確認する。`npm run dev` は表示が遅く、体感が実際と異なる |
| 2 | 管理者アカウント 1つ | D1 の `users` に `role='admin'` |
| 3 | **オーナーアカウント 2つ** | 「自分の申請」と「他人の申請」を分けるため。**2つ目は権限テストに必須** |
| 4 | テンプレート 3件（すべて「販売可」） | 0件だと自動選択が確認できない |
| 5 | テスト用画像 4種 | JPEG / PNG / **HEIC**（iPhone写真）/ **9MB超**の大きい画像 |

### 💰 課金が発生するケース

| ケース | 内容 | 目安 |
|---|---|---|
| A-13, A-14, A-18, A-21 | サイト作成（文章＋画像20枚） | 1回あたり数分 |
| A-31, A-32 | テンプレート作成 | 1回あたり30秒〜1分 |
| U-54 | セクションのAI書き直し | 1回あたり5秒 |

**回帰テストではサイト作成を1回だけ**にしてください。

### ⚠️ トンネル経由でテストする場合

URLに認証情報を埋め込まないでください。

```
❌ https://client:パスワード@xxxx.trycloudflare.com
⭕️ https://xxxx.trycloudflare.com  ← ダイアログに入力する
```

埋め込むと**保存・ログイン・画像アップロードなど、送信を伴う操作がすべて失敗**します（ブラウザの仕様）。

| ID | 確認すること | 期待 |

## 16. 装飾と動き（O-01〜O-10）

O-01〜O-08 は自動で確認できます。**AI も D1 も使わないので、認証情報も課金も不要です。**

```bash
npx tsx scripts/check-ornaments.mts
```

| ID | 確認すること | 期待 |
|---|---|---|
| O-01 | 安全規則（site.css を機械的に読む） | 装飾は `absolute` + `inset:0` + `pointer-events:none`／負のマージンが無い |
| O-02 | **常時アニメが「動きなし」を尊重するか** | `data-ambient` を読む規則が**すべて** `:not([data-reveal="none"])` で守られている |
| O-03 | 既定値のドキュメント | 装飾レイヤーも読み進みバーも出ない（既存サイトの出力は変わらない） |
| O-04 | 有効にしたとき | セクションの数だけ装飾レイヤーが出る／`data-ambient` が渡る |
| O-05 | **背景写真のパス** | 規則がページ内の `<style>` に出て、`url("images/…")` が直接書かれている（site.css 経由だと `css/images/…` になって出ない） |
| O-06 | 背景写真の安全策 | スクリムが重なる／動きを控える設定と 767px 以下で固定が外れる／写真が無い間は指定ごと無効 |
| O-07 | 流れる写真の帯 | 2周目の複製に `data-field` が無い（編集画面の対応付けが一意）／支援技術から隠れている |
| O-08 | 画像の台帳 | 背景ありのときだけスロットが1つ増える／生成されたパスが書き戻る／生成されなければ消える |
| O-09 | 描画検査（390px / 1280px、6通り） | 横スクロール・画像切れ・はみ出しが 0 |

⚠️ **O-10 は人が画面で確認します。**

| ID | 手順 | 期待 |
|---|---|---|
| O-10 | 編集画面 → デザイン → 「セクションの地紋」「地紋を動かし続ける」「背景写真」「読み進み具合のバー」を切り替える | 柄がテーマカラーで出る／地紋だけが動き、文字は動かない／バーが最上部に出る |

見比べたいときは `--keep` を付けると `/generated/__orn-*/` に 6 通りが残ります（もう一度 `--keep` 無しで実行すると片付きます）。

⚠️ **地紋の濃さの既定値は 0.16 です。** 0.3 では柄がページでいちばん強い要素になり、カードが壁紙の上に浮いて見えます（実測して下げました）。

⚠️ **背景写真は AI が生成します。** テンプレートで有効にすると画像スロットが 1 つ増え、サイト生成時の画像枚数と費用が 1 枚分増えます。

⚠️ **OSの「視差効果を減らす」を ON にして確認してください。** 地紋の動きと写真の帯が止まり、帯の写真は折り返して全部見える状態になります。

## 17. 装飾の自動割り当てとテンプレートの写真（N-01〜N-08）
